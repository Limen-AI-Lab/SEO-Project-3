### 2.2 Reference 网页抓取与分析

#### **目标功能**
在生成 Outline 和 Draft 时，自动从 Google 搜索抓取相关网页作为参考资料。

#### **实现方案**

##### **方案 A: 使用 SerpAPI（推荐）**
- **服务**: [SerpAPI](https://serpapi.com/)
- **优势**: 提供结构化的 Google 搜索结果，包含 snippets
- **实现步骤**:
  1. 注册 SerpAPI 获取 API Key
  2. 创建 `services/serpService.ts`:
     ```typescript
     export async function searchGoogle(query: string, location: string = 'United States') {
       const apiKey = import.meta.env.VITE_SERP_API_KEY;
       const params = new URLSearchParams({
         q: query,
         location: location,
         hl: 'en',
         gl: 'us',
         api_key: apiKey
       });
       
       const response = await fetch(`https://serpapi.com/search?${params}`);
       const data = await response.json();
       
       return data.organic_results.slice(0, 10).map(result => ({
         title: result.title,
         snippet: result.snippet,
         url: result.link,
         date: result.date || 'N/A'
       }));
     }
     ```
  3. 在 `StageOutline.tsx` 调用:
     ```typescript
     useEffect(() => {
       const fetchReferences = async () => {
         const keyword = project.selectedTitle || project.title;
         const results = await searchGoogle(keyword);
         setReferences(results);
       };
       fetchReferences();
     }, [project.title]);
     ```

##### **方案 B: 使用 Google Custom Search API**
- **服务**: Google Custom Search JSON API
- **优势**: 官方 API，更稳定
- **限制**: 免费版每天 100 次查询
- **实现类似方案 A**

##### **方案 C: 使用 Web Scraping（不推荐）**
- **工具**: Puppeteer / Playwright
- **问题**: 需要服务器端支持，易被 Google 屏蔽
- **仅作为备选方案**

### 2.3 Keyword Discovery 真实搜索集成

#### **目标功能**
用户输入关键词后，系统应真实查询 Google 趋势、关键词难度等数据。

#### **实现方案**

##### **方案 A: 使用 SEMrush API（推荐）**
- **服务**: [SEMrush API](https://www.semrush.com/api-documentation/)
- **功能**: 关键词难度、搜索量、相关关键词
- **实现步骤**:
  1. 注册 SEMrush 获取 API Key
  2. 创建 `services/keywordService.ts`:
     ```typescript
     export async function getKeywordData(keyword: string, database: string = 'us') {
       const apiKey = import.meta.env.VITE_SEMRUSH_API_KEY;
       const url = `https://api.semrush.com/?type=phrase_these&key=${apiKey}&phrase=${keyword}&export_columns=Ph,Nq,Cp,Co,Nr&database=${database}`;
       
       const response = await fetch(url);
       const data = await response.text();
       
       // Parse CSV response
       return parseKeywordData(data);
     }
     ```

##### **方案 B: 使用 Ahrefs API**
- **服务**: [Ahrefs API](https://ahrefs.com/api)
- **功能**: 关键词难度、搜索量、SERP 分析
- **价格**: 较贵，适合专业 SEO 机构

##### **方案 C: Google Trends API（免费但有限）**
- **服务**: `google-trends-api` npm 包
- **功能**: 相对趋势数据，无具体搜索量
- **实现**:
  ```typescript
  import googleTrends from 'google-trends-api';
  
  export async function getKeywordTrends(keyword: string) {
    const results = await googleTrends.interestOverTime({
      keyword: keyword,
      startTime: new Date(Date.now() - 30 * 24 * 60 * 60 * 1000)
    });
    return JSON.parse(results);
  }
  ```

```sql
CREATE TABLE article_versions (
  id UUID DEFAULT uuid_generate_v4() PRIMARY KEY,
  article_id UUID REFERENCES articles(id) ON DELETE CASCADE,
  version_number INT NOT NULL,
  content JSONB,  -- 存储当时的 outlineContent, draftContent, draftBlocks
  created_by VARCHAR(255),
  created_at TIMESTAMP DEFAULT NOW()
);
```

在保存文章时自动创建版本:
```typescript
async function saveArticleVersion(articleId: string, userId: string) {
  const article = await getArticleById(articleId);
  
  const { data: latestVersion } = await supabase
    .from('article_versions')
    .select('version_number')
    .eq('article_id', articleId)
    .order('version_number', { ascending: false })
    .limit(1)
    .single();
  
  const versionNumber = (latestVersion?.version_number || 0) + 1;
  
  await supabase.from('article_versions').insert({
    article_id: articleId,
    version_number: versionNumber,
    content: {
      outlineContent: article.outlineContent,
      draftContent: article.draftContent,
      draftBlocks: article.draftBlocks
    },
    created_by: userId
  });
}
```
